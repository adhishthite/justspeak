# JustSpeak Custom Vocabulary
# ============================
# Add custom words, domain terms, technical acronyms, or teammate names (one per line).
# Lines starting with '#' are comments and ignored. Empty lines are ignored.
#
# Usage:
#   1. Copy this file to 'vocabulary.txt' (auto-loaded by JustSpeak):
#      cp vocabulary.example.txt vocabulary.txt
#   2. Or set CUSTOM_VOCABULARY="word1, word2, word3" in your .env
#   3. Or set CUSTOM_VOCABULARY_FILE="path/to/my_vocab.txt" in your .env
#
# A line containing "=>" is a deterministic replacement rule instead of a plain boost
# term - the misheard form is rewritten to the right-hand side after transcription, and
# the right-hand side is also added to the boost vocabulary:
#   cooper netties => Kubernetes
#
# A "# context: ..." line describes who is dictating. It never affects recognition; it is
# read only by `make analyze`, which uses it to judge what a garbled phrase plausibly meant
# (multiple context lines are joined; the ANALYZE_CONTEXT env knob overrides them):
#   context: Solutions architect; daily terms are GCP services, AI products, customer names.
